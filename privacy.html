Privacy policy

Storylight Cinema Studio · last updated 4 October 2026

Storylight Cinema Studio is a private tool its owner uses to publish original story videos to the owner's own YouTube channel. It is not offered to the public, and nobody else signs in to it.

What it accesses

With the owner's permission, through Google OAuth, it uses the YouTube Data API and the YouTube Analytics API to:

  • upload the owner's videos and thumbnails to the owner's channel;
  • read which channel a sign-in belongs to, so videos never go to the wrong channel;
  • read view and watch-time numbers for the owner's own channel.

What it stores

Sign-in tokens and the owner's channel statistics are stored only on the owner's computer. Nothing is stored on a server.

What it shares

Nothing. No data is sold, shared or shown to anyone else.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the local token files also ends access.

Google policies

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
